⚠ Warning BED005

Intervals are sorted

What this means

The BED file is not sorted: some intervals start before the interval above them. Several common tools (bedtools, tabix, many variant callers) need sorted regions and will stop, or quietly give wrong answers, if they are not.

How to fix

Run: preflight fix-bed --sort <file> --out <sorted file>. Add --reference to sort in reference order.

Technical detail

Sorted means every chromosome is one contiguous block, starts do not decrease inside a block, and the blocks follow either the reference order (when a reference is given) or plain alphabetical order (as produced by 'sort -k1,1 -k2,2n').

What this means

Counted as written, the targets add up to 2,579 bp, but they cover only 2,539 bp once overlaps are merged (10 regions become 8). How to fix
