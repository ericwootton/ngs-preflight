⚠ Warning BED005

Intervals are sorted

What this means

The BED file is not sorted: some intervals start before the interval above them. Some commonly used tools (bedtools, tabix, and many variant callers) require sorted regions. If regions are not sorted, these tools will stop running or quietly return incorrect results.

How to fix

Run preflight fix-bed --sort <file> --out <sorted file>. To sort in reference sequence order, add --reference.

Technical detail

Sorted means that each chromosome forms a single continuous block and start positions within each block do not decrease. These blocks follow reference sequence order (if a reference sequence is specified) or simple alphabetical order (the order produced by 'sort -k1,1 -k2,2n').
